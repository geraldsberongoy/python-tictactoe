# Python Tic-Tac-Toe

A simple command-line Tic-Tac-Toe game for two players written in Python.

## Features
- Two-player gameplay in the terminal
- Player marker selection (`X` or `O`)
- Input validation for moves
- Win detection (rows, columns, diagonals)
- Replay option after each game

## Requirements
- Python 3.x

## Run the game
From the repository root:

```bash
python tictactoe.py
```

## How to play
1. Choose whether Player 1 will use `X` or `O`.
2. Enter moves as `row column` using values from `1` to `3` (example: `1 3`).
3. Players take turns until one player gets three in a row or the game ends in a tie.
4. Choose `Y` to play again or `N` to exit.
